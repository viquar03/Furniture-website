WoodCraft Studio - Carpenter Shop Website
=========================================

Files Included:
1. index.html  - Complete structure of the website (Hero, Services, Filterable Gallery, About, Contact & Modal)
2. style.css   - Warm wood-toned responsive design for mobile and desktop
3. script.js   - JavaScript functionality for all interactive buttons:
                 * Category Filter Buttons (All, Sofas, Cabinets, Curtains)
                 * Quick Inquiry Popup Modal ("Inquire Now" & "Book Free Measurement")
                 * Service "Get Estimate" Auto-Select & Smooth Scroll
                 * WhatsApp Direct Chat Button
                 * Mobile Menu Toggle & Back-to-Top Button

How to Run:
- Extract this ZIP folder.
- Double-click on `index.html` to open it in any web browser (Chrome, Edge, Safari, etc.).
- You can edit text, phone numbers, or add your real shop photos inside `index.html` and `style.css`.
